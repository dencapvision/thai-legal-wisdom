# Thai Legal Wisdom — อาจารย์กฎหมาย AI

เว็บแอปภาษาไทยสำหรับเรียนรู้หลักการตีความกฎหมาย และเตรียมคำถามพร้อมบริบทเพื่อนำไปวิเคราะห์ต่อใน ChatGPT Projects หรือ Custom GPT

## ความสามารถ

- เลือกคำอธิบายสำหรับประชาชน ผู้บริหาร/เจ้าหน้าที่ หรือนักวิชาการ/นักวิจัย
- ป้อนคำถาม ข้อเท็จจริง หรือข้อความกฎหมาย และแนบไฟล์ `.txt` / `.md` ไม่เกิน 100 KB
- สร้างชุดคำสั่งตามกรอบวิเคราะห์ 6 ขั้นตอน พร้อมคัดลอกและเปิด ChatGPT
- บันทึกประเด็นใน `localStorage` ของเบราว์เซอร์ และกลับมาเปิดหรือลบได้
- อ่านหลักการตีความ 6 มิติ และลิงก์ไปยังแหล่งข้อมูลกฎหมายทางการ
- คัดลอกหรือดาวน์โหลด Custom Instructions

แอปยังไม่มีโมเดล AI หรือระบบตรวจสอบกฎหมายฉบับปัจจุบันในตัว คำตอบวิเคราะห์ต้องดำเนินการต่อใน ChatGPT และตรวจสอบกับแหล่งข้อมูลทางการ ข้อมูลที่บันทึกไม่ซิงก์ข้ามอุปกรณ์และอาจสูญหายเมื่อล้างข้อมูลเบราว์เซอร์

## บทวิเคราะห์กฎหมายเฉพาะเรื่อง

เปิดหน้า `/#acts` เพื่ออ่านบทวิเคราะห์ พ.ร.บ.สภานโยบายการอุดมศึกษา วิทยาศาสตร์ วิจัยและนวัตกรรมแห่งชาติ พ.ศ. 2562 และ (ฉบับที่ 2) พ.ศ. 2568 พร้อมตารางเปรียบเทียบมาตรา 12 (1) บทบาทหน่วยงาน ตัวอย่าง และรายการตรวจสอบสำหรับผู้ปฏิบัติงาน ดาวน์โหลดบทวิเคราะห์เป็นข้อความได้

เนื้อหาอยู่ใน `dist/legal-analysis.js` ตรวจตัวบทจากสำเนาราชกิจจานุเบกษาที่สภานโยบายเผยแพร่ เมื่อ 20 ตุลาคม 2569 โดยตรวจภาพฉบับแก้ไขทั้ง 3 หน้า เนื่องจากข้อความที่สกัดจาก PDF บางส่วนผิดเพี้ยน หน้านี้เป็นบทวิเคราะห์ที่เรียบเรียงไว้ ไม่ใช่การวิเคราะห์สดด้วยโมเดล และไม่รับรองว่าตรวจครบกฎหมายลำดับรองหรือการแก้ไขทุกฉบับถึงวันใช้งาน

## เปิดใช้งานในเครื่อง

ไม่ต้องติดตั้ง dependencies หรือ build:

```sh
python3 -m http.server 8000 --directory dist
```

เปิด `http://localhost:8000` ในเบราว์เซอร์ การคัดลอกข้อความต้องใช้ HTTPS หรือ localhost และอาจขึ้นอยู่กับสิทธิ์ของเบราว์เซอร์

## โครงสร้าง

- `dist/index.html` — โครงหน้าและกล่องแสดงชุดคำสั่ง
- `dist/style.css` — รูปแบบหน้าจอและ responsive layout
- `dist/app.js` — หน้าต่าง ๆ ชุดคำสั่ง การแนบไฟล์ และการบันทึกประเด็น
- `.openai/hosting.json` — การตั้งค่า Sites ของโครงการเดิม

## ตรวจสอบโค้ด

```sh
node --check dist/app.js
```

## การเผยแพร่

เว็บไซต์ใช้ Sites โดยคง Project ID เดิมไว้ใน `.openai/hosting.json` การ push ไป GitHub เพียงอย่างเดียวไม่ได้ deploy ไป Sites โดยอัตโนมัติ ต้องซิงก์ source และเผยแพร่ผ่าน Sites workflow แยกต่างหาก

Google Fonts เป็นทรัพยากรภายนอก หากโหลดไม่ได้จะใช้ฟอนต์สำรองในเครื่อง ไม่มี API key ฝังในโค้ด

เครื่องมือนี้สนับสนุนการเรียนรู้และเตรียมการวิเคราะห์ ไม่ทดแทนคำปรึกษาจากผู้ประกอบวิชาชีพกฎหมายในกรณีเฉพาะ
